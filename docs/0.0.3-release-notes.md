# tern 0.0.3 alpha

Third Apple Silicon alpha prerelease. It makes tern usable as an everyday terminal, moves every
app shortcut into one registry with Mac-native defaults, and gives panes a quieter card layout.
The app targets macOS 14 or later; testing on macOS 14 and on a separate Mac is still outstanding.

## Changes since 0.0.2

### Everyday terminal

- Independent windows with their own layout and restored geometry. Tabs and panes can move
  between windows, and the palette's session search and ⌘J / ⇧⌘J attention navigation cover
  every window.
- Shell integration for zsh, bash and fish: prompt navigation, exit status and duration,
  alerts for long background commands, and Copy Last Output (⇧⌘C).
- Retained history is shared with the daemon. Export scrollback (⇧⌘S), open it in an editor,
  find with regex or case matching (⌥⌘F), and search output across every session (⇧⌘F).
- File drops are shell-quoted, `file:line` links open in your editor, image paste is
  supported, and ⌥⌘V pastes a PNG's path. Pasting files copied in Finder types their full paths.
- `tern open` and `tern .`, a Finder service, and URL opening.
- Detach a session and reattach it later from the detached-session browser. Reopen a closed
  tab with ⇧⌘T.
- An optional system-wide hotkey, accessibility text and selection, a native context menu and
  Secure Keyboard Entry.
- tern → Check for Tern Updates… finds GitHub releases, verifies the download's checksum,
  signature and Gatekeeper assessment, and installs only when you choose Install and Relaunch.

### Shortcuts

- Every shortcut is declared in one registry, and the menu bar, palette, sidebar hints,
  Settings and README read from it. Every binding uses ⌘ (⌃⇥ aside), so ⌃ and ⌥ keys always
  reach the terminal, and none takes a key macOS reserves.
- Moved defaults: tab N is ⌃⌘1–9 (⇧⌘3/4/5 belong to screenshots), the palette is ⇧⌘P, ⌘K
  clears, ⇧⌘K opens SSH, zoom pane is ⇧⌘↩, the sidebar is ⌃⌘S, and a worktree tab is ⌥⌘T.
  The old ⌘↩ and ⌘\ still work.
- Existing overrides in Settings → Terminal → App shortcuts keep working. An override that
  breaks a rule or clashes is reported and the default is used.
- Help → Keyboard Shortcuts (⌘/) lists every live binding with a filter.

### Look and feel

- Panes are rounded cards with a header showing status, what runs there and its directory.
  Panes without focus are dimmed.
- Splits, closes, tab switches and the palette animate on one curve; Reduce Motion turns them
  into fades.
- Quick Settings (⇧⌘,) changes theme, text size, cursor, Option as Alt and more from the
  palette, previewing themes as you move.
- Closing a pane focuses the pane before it instead of the first one.

## Install

Download `Tern-0.0.3-macos-arm64.zip` and its `.sha256` file, then verify them:

```sh
shasum -a 256 -c Tern-0.0.3-macos-arm64.zip.sha256
```

Unzip it and move `Tern.app` to Applications. The app is signed with Developer ID, notarized and
carries a stapled ticket. Intel Macs need a separate build.

Upgrading from 0.0.2: **the daemon protocol is now 2**, so tern offers to restart ternd for the
new build. A restart ends the programs running in your tabs; their screens come back and agent
conversations resume. 0.0.2 has no in-app updater, so install this release by hand.

The source bundle includes tern, the pinned Ghostty checkout, fetched native dependency sources
and vendored Rust crates. `SOURCE_BUILD.md` in that archive records the exact commits and rebuild
instructions. The source bundle has its own SHA-256 checksum.

## Known limitations

- Notification banners don't work reliably yet. Dock badges and ⌘J don't depend on them.
- Copy/paste inside Codex is an open issue.
- A reboot or daemon restart ends running processes; saved screens return and supported agent
  conversations can resume.
- Saved screens don't capture a full-screen program's screen or image pixels, and agent
  completion is inferred without hooks.
- Launch-preset environment values and saved terminal output are local plaintext files,
  readable only by you.
