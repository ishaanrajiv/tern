# tern 0.0.4 alpha

Fourth Apple Silicon alpha prerelease. Updates for tern, ternd, Claude Code and Codex now share one
card in the sidebar, agent updaters run out of sight instead of in a tab, and tabs name themselves
after what they run. The app targets macOS 14 or later; testing on macOS 14 and on a separate Mac
is still outstanding.

## Changes since 0.0.3

### Updates

- One card at the bottom of the sidebar lists every pending update: a new tern release, a ternd
  older than the app, and new Claude Code or Codex versions. A row that needs you comes first with
  an amber outline; the rest shrink to one line each.
- tern releases download and are checked in the background, then install when tern quits, or
  right away with Restart. Sessions keep running in ternd either way. Remind Tomorrow and Skip
  This Version apply per release.
- Claude Code and Codex update in a hidden ternd session instead of a tab. The card shows the
  command, how long it has run and its last line. If the updater asks a question, the card quotes
  it and a small console opens so you can answer. A failed run keeps the console open with Retry,
  Close and Copy Output; a successful one closes by itself. Updaters keep running if you quit
  tern, and the next launch picks them up.
- Restart ternd asks first and lists what a restart would end, including busy shells and running
  updaters. When Idle waits until no tab is running anything.
- tern warns when more than one copy of an agent is on your PATH, since an update may land in the
  copy you don't run. Homebrew installs update with `brew upgrade --cask`.
- Settings → Updates lists each version with its state and holds the update options.

### Tabs and status

- A command names its tab only after it has run for 3 seconds, so `git status` no longer renames
  the tab. Without a command, a tab uses its subfolder, a renamed worktree branch or a dimmed
  "Shell".
- Claude Code tabs take the conversation's title (`/rename` wins), and Codex tabs take the
  thread name.
- The pane header no longer shows "last exit 0 · 0.0s". A success that took 10 seconds or more
  shows "Done in 2m 14s"; a failure shows in red as "Failed", "Command not found", "Not
  executable", "Killed" or "Terminated", with the code and duration in the tooltip.
- Claude Code no longer looks busy after a turn ends while a helper agent finishes.
- New splits no longer start with "Last login: …".
- A refused Keychain prompt no longer turns off Claude account usage. Settings shows "macOS
  blocked access" with Try Again.

## Install

Download `Tern-0.0.4-macos-arm64.zip` and its `.sha256` file, then verify them:

```sh
shasum -a 256 -c Tern-0.0.4-macos-arm64.zip.sha256
```

Unzip it and move `Tern.app` to Applications. The app is signed with Developer ID, notarized and
carries a stapled ticket. Intel Macs need a separate build.

Upgrading from 0.0.3: tern → Check for Tern Updates… finds this release. The daemon protocol stays
at 2, so the new app works with a running 0.0.3 ternd. Tab naming, the busy-shell check and the
helper-agent fix need the new ternd, which the update card offers to restart when idle. A restart
ends the programs running in your tabs; their screens come back and agent conversations resume.

The source bundle includes tern, the pinned Ghostty checkout, fetched native dependency sources
and vendored Rust crates. `SOURCE_BUILD.md` in that archive records the exact commits and rebuild
instructions. The source bundle has its own SHA-256 checksum.

## Known limitations

- Notification banners don't work reliably yet. Dock badges and ⌘J don't depend on them.
- Copy/paste inside Codex is an open issue.
- A reboot or daemon restart ends running processes; saved screens return and supported agent
  conversations can resume.
- Saved screens don't capture a full-screen program's screen or image pixels, and agent
  completion is inferred without hooks.
- Launch-preset environment values and saved terminal output are local plaintext files,
  readable only by you.
- Agent updates and shell integration have been tried with zsh only.
