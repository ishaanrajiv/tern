# tern 0.0.1 alpha

First private Apple Silicon release candidate for maintainer testing. The app targets
macOS 14 or later; this candidate has not yet been tested on macOS 14 or a separate Mac.

The app provides persistent terminal sessions, folders, tabs, split panes, search,
Claude Code and Codex status, project launch presets, and SSH connections.

## Install

Download `Tern-0.0.1-macos-arm64.zip` and its `.sha256` file, then verify them:

```sh
shasum -a 256 -c Tern-0.0.1-macos-arm64.zip.sha256
```

Unzip it and move `Tern.app` to Applications. The release candidate is signed with
Developer ID, notarized and carries a stapled ticket. Intel Macs need a separate build.

The source bundle includes tern, the pinned Ghostty checkout, fetched native dependency
sources and vendored Rust crates. `SOURCE_BUILD.md` in that archive records the exact
commits and rebuild instructions. The source bundle has its own SHA-256 checksum.

## Known limitations

- Runtime permissions, session ID validation, message/queue limits, hook and resume
  quoting, and account-usage consent still need the fixes recorded in the release plan.
  Keep this candidate limited to maintainer testing until that work is complete.
- Notification banners do not currently work reliably. Dock badges and next-agent navigation
  are independent of notification permission.
- Copy/paste inside Codex remains an open issue. Text and image clipboard handling need
  separate validation.
- Sessions survive quitting the app. A reboot or daemon restart ends the running processes;
  saved screens can return and supported agent conversations can resume.
- Saved screens do not capture a full-screen program's active screen, and inferred agent
  completion can be inaccurate without hooks.
- Launch-preset environment values and saved terminal output are local plaintext files.

See README.md for behavior and docs/public-readiness.md for the current distribution review.
