# tern 0.0.2 alpha

Second Apple Silicon alpha prerelease, and the first since the repository became public. It
fixes the runtime issues found in the [public-readiness review](public-readiness.md). The app
targets macOS 14 or later; testing on macOS 14 and on a separate Mac is still outstanding.

## Changes since 0.0.1

- ternd keeps `~/Library/Application Support/tern` private: `0700` folders, `0600` files and
  socket, repaired on start. It refuses connections from other users, and refuses a runtime
  folder that is a symlink or belongs to another user. Programs in your tabs keep your umask.
- Session ids that aren't plain file names are rejected before any file is touched.
- Request lines, client frames and each client's pending output are bounded. A client that
  falls behind reconnects from the screen instead of growing the daemon's memory.
- Agent conversation ids and tern's own path are shell-quoted when typed or installed as hooks.
  Hooks from 0.0.1 are recognised and replaced when you set them up again.
- Hook setup writes through a symlinked agent config to its real file and keeps its permissions.
- **Reading Claude account usage is now off by default.** Turn it on in Settings → Agents if you
  want limits from the account; Settings explains what it reads and sends.
- Release builds no longer contain the debug harness.
- Building from source verifies every Ghostty Zig dependency against its pinned hash.
- New [SECURITY.md](../SECURITY.md), [CONTRIBUTING.md](../CONTRIBUTING.md) and a Privacy
  section in the README.

## Install

Download `Tern-0.0.2-macos-arm64.zip` and its `.sha256` file, then verify them:

```sh
shasum -a 256 -c Tern-0.0.2-macos-arm64.zip.sha256
```

Unzip it and move `Tern.app` to Applications. The app is signed with Developer ID, notarized and
carries a stapled ticket. Intel Macs need a separate build.

Upgrading from 0.0.1: tern offers to restart ternd for the new build. A restart ends the
programs running in your tabs; their screens come back and agent conversations resume.

The source bundle includes tern, the pinned Ghostty checkout, fetched native dependency sources
and vendored Rust crates. `SOURCE_BUILD.md` in that archive records the exact commits and rebuild
instructions. The source bundle has its own SHA-256 checksum.

## Known limitations

- Notification banners don't work reliably yet. Dock badges and ⌘J don't depend on them.
- Copy/paste inside Codex is an open issue.
- A reboot or daemon restart ends running processes; saved screens return and supported agent
  conversations can resume.
- Saved screens don't capture a full-screen program's screen, and agent completion is inferred
  without hooks.
- Launch-preset environment values and saved terminal output are local plaintext files,
  readable only by you.
